## `client-portal-prototype/`

The Fintra client portal prototype, authored by the senior engineer, extracted
verbatim from `client_portal_react.rar`. It is committed so that the rebuild has
a stable, line-addressable baseline to compare against across sessions.

Its own documentation lives in `client-portal-prototype/doc/`:

- `PROJECT.md` — stack, token table, component catalogue
- `LINE_CHART.md` — the pure-SVG sparkline and hover tooltip

`package-lock.json` was dropped; the dependency versions in `package.json` are
the record that matters.
